# DSA Algorithm Visualizer

A simple and interactive **DSA Algorithm Visualizer** developed using **HTML, CSS, and JavaScript**.  
The project helps students understand basic algorithms through step-by-step visual animations.

## Project Overview

The DSA Algorithm Visualizer provides a simple web-based interface where users can select an algorithm and watch how it works visually.

This project is inspired by online algorithm visualization projects and is designed for educational and beginner-friendly use.

## Algorithms Included

### Sorting Algorithms
- Bubble Sort
- Selection Sort

### Searching Algorithms
- Linear Search
- Binary Search

### Graph Traversal Algorithms
- Breadth First Search (BFS)
- Depth First Search (DFS)

## Features

- Interactive algorithm visualization
- Step-by-step animation
- Start, Pause, and Reset controls
- Generate a new random array
- Adjustable animation speed
- Search value input for searching algorithms
- Displays time complexity
- Displays space complexity
- Simple and responsive user interface

## Technologies Used

- **HTML5** – Structure of the website
- **CSS3** – Styling and responsive design
- **JavaScript** – Algorithms, animations, and interaction

## How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all three files are in the same folder:
   - `index.html`
   - `style.css`
   - `script.js`
4. Open the project using **Live Server**.
5. Select an algorithm from the dropdown menu.
6. Click **Start** to begin the visualization.

## Algorithm Complexity

| Algorithm | Time Complexity | Space Complexity |
|---|---|---|
| Bubble Sort | O(n²) | O(1) |
| Selection Sort | O(n²) | O(1) |
| Linear Search | O(n) | O(1) |
| Binary Search | O(log n) | O(1) |
| BFS | O(V + E) | O(V) |
| DFS | O(V + E) | O(V) |

## Controls

- **New Array** – Generates a new random array.
- **Start** – Starts the selected algorithm.
- **Pause** – Pauses the animation.
- **Reset** – Resets the visualization.
- **Speed** – Controls the animation speed.
- **Search Value** – Specifies the value to search for in Linear Search and Binary Search.

## Purpose

The main purpose of this project is to make Data Structures and Algorithms easier to understand by representing their operations visually instead of only using code and theory.
